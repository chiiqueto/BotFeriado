# 🎌 FeriadoBot

Bot do Telegram que mostra os feriados nacionais do ano e o próximo feriado.

**Grupo:** GCA03 — **Integrantes:** Camilli e Julia

**API:** [BrasilAPI](https://brasilapi.com.br) (`/api/feriados/v1/{ano}`), pública e sem chave.

**Comandos:** `/feriados` lista os feriados do ano; `/proximo` mostra o próximo feriado.

**Como rodar:**
1. Crie o bot com o @BotFather e copie o token.
2. `pip install -r requirements.txt`
3. Copie `.env.example` para `.env` e cole o token.
4. `python bot.py`
